## What the ruling changed — three things, all from bytes

**1. The measure half is already done.** An intensive coefficient needs a per-cell
measure *and* a naturality law for it. Both are derived of record: T11 has
`each cell contributes V_cell sum F^2` and `general coframe = pullback by
wedge^2(e^-1) times |det e|`, with the substantive line *"the measure is forced, not
chosen"*. The stitching decomposition draws the consequence outright — the coframe
transformation *"is already a pullback … exactly the naturality law a measure needs.
**The measure's own stitching is done.**"* So the index does not have to supply, adopt,
or choose a measure; it has to be a system the derived measure already transforms along.
**My 716 fork was too pessimistic by one whole component** — and the component readers
would expect to be hardest.

**2. The index's missing content is named, in three items, by sealed text.** A category
`Ref_0` is already **BUILT** (`FINITE_REALIZATION_SKELETON_J_0 = BUILT / TYPE-P`),
directed by everything except geometric refinement. Its stated lack: its arrows *"do
not say that cells shrink, that two complexes cover the same region, or that a new cell
refines an old one."* So the free choice is not "invent a same-region relation" — it is
**P1 cells shrink / P2 same region / P3 refines**, added to a built category. For three
relays I have called this ground "the same-region relation"; that is P2 alone, and a
package delivering only it would be under-specified against its own source.

**3. The shape condition now gates RA27-2.** It did not before. The ruled subject is
*intensive* — invariance up to a boundary term whose **ratio to four-volume** tends to
zero — and the held conflict is precisely whether slivers are admitted, whose risk the
conflict determination itself states in four-volume terms (*"if a sliver of volume
eps*|C|_4 produces an O(|C|_4) response defect, the object FAILS"*). **This is a
promotion, not a resolution**: the conflict remains yours, PRODUCTION stays PROHIBITED,
D3 is not narrowed, no shape condition is adopted. And I have not shown a sliver *does*
break the ratio — that conditional is unresolved, and evaluating it would require
exactly the downstream computation the void condition bars.
