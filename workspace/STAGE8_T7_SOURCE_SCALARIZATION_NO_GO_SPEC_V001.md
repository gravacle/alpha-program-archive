## Frozen problem

The one-handle public transition is a map between complex lines and is
therefore canonically scalar after connection return. The connected
source-record parent instead produces, after projection onto a completed
record outcome,

```text
K(A) in End(H_source).
```

The gate asks whether the existing structure canonically supplies a
normalized complex-linear functional

```text
C:End(H_source)->C,  C(I)=1,
```

that is compatible with source covariance, the one-handle line reduction,
and the continuum source carrier.

## N1 - Non-scalar parent witness

Read the sealed actual-parent report and verify that its completed `11`
compression is full rank and has nonzero distance from every scalar
multiple of the identity. No source state, source ray, trace, determinant,
or endpoint may be added to change this witness.

## N2 - Finite-dimensional covariance theorem

For `M_d(C)`, classify every complex-linear functional invariant under
unitary conjugation:

```text
C(UKU^dagger)=C(K).
```

Using matrix units, prove that invariance kills every off-diagonal unit and
makes all diagonal-unit values equal. Unit normalization must then force:

```text
C(K)=Tr(K)/d.
```

Verify this independently by solving the linear invariance equations for
the `d=2` matrix units under a target-free generating set of unitaries.

## N3 - Continuum obstruction

The source carrier is not canonically finite-dimensional. Prove that
`B(H)` for infinite-dimensional `H` has no normalized tracial state. Use
two isometries `V_1,V_2` with orthogonal ranges satisfying:

```text
V_i^dagger V_i=I;
V_1 V_1^dagger+V_2 V_2^dagger=I.
```

A normalized trace would imply:

```text
1=Tr(I)
 =Tr(V_1 V_1^dagger)+Tr(V_2 V_2^dagger)
 =Tr(I)+Tr(I)=2,
```

which is impossible.

The finite normalized trace therefore does not define a
regulator-independent canonical continuum scalarization.
