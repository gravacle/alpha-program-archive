## §1 — Q1: THE CANDIDATE GRADINGS

### §1.0 THE TEST, STATED BEFORE IT IS RUN

A site earns **BOTH-DERIVED-RESERVATION-SOLE-BLOCKER** only if all three hold at
bytes:

```text
(E)  EXISTENCE of the needed object is DERIVED — not displayed, not demanded,
     not conditional on the object itself;
(U)  UNIQUENESS of that same object is DERIVED — an at-most-one about the
     OBJECT, not a sole-ness about the DEMAND;
(R)  the ONLY thing preventing entry is that entry would be an authored act.
     If any further blocker stands — a type mismatch, a standing prohibition,
     an unlanded input — the site FAILS (R) however strong (E) and (U) are.
```

The (U) distinction is not mine; the corpus draws it, and I adopt its words.
`STAGE8_DISCHARGERS_VS_PARTITION_O11SR_V001.md` §2.1 (seal OK), quoted whole
including its bracketed provenance:

> "**THE SOLE-NESS IS A PROPERTY OF THE DEMAND, NOT OF THE OBJECT.** "Only sealed conversion",
> "only displayed replacement", "only permitted certification" quantify over the record's
> displayed ROUTES; they say which object WOULD discharge, not that the object exists. The
> completion map itself keeps the mood: a landing "at derived grade with derived
> existence-and-uniqueness **WOULD** instantiate SHAPE-1 (single require, unique root) per leg"
> (§4.1) — conditional, and its antecedent is precisely what is missing. [CAS C3.]"
