## 5. Target-independence test

The observable distinction is frozen dependency and output invariance, not author intent. The
opposite-lane check applies this five-part test:

1. **Freeze:** before execution, hash the B01 input, F06 code/interface, all parameters, manifest,
   randomness/seed material, F09 oracle, and output schema. Reject any later mutation.
2. **Allowlist:** the constructor-read transcript may contain only declared B01 rows and declared
   neutral runtime/schema bytes. Reads of C0/U1/U2/U3 descendants, response output, root information,
   a B0 discharge flag, item-1 realization, or target-selected success value fail.
3. **Replay:** two executions from the identical frozen bundle must yield the same candidate-record
   digest and trace semantics. Any nondeterminism must itself be frozen as an input; undeclared entropy
   fails.
4. **Counterfactual mask:** with the frozen B01 bundle unchanged, withhold or perturb every downstream
   target/output/root channel. F06 must still execute and emit the identical F01–F07 digests. A missing
   channel that changes, blocks, or selects the output exposes tuning.
5. **No supplement:** compare the pre-run input/field manifest to the sealed candidate. Any required
   datum added after a consumer/output was inspected fails even if the datum is otherwise valid.

This is the strongest checkable predicate derivable from A03 and demand conditions 14–17/21 using
