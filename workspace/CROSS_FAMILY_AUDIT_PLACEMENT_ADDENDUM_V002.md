## THE RULING

System-independent adversarial reviewers (Grok Super Heavy, Gemini) touch NOTHING until alpha is
computed AND the blind test is scored. NO cross-family model reviews any in-flight or pre-run
artifact. Rationale: a computed number cannot be tuned by a review; keeping reviewers strictly
downstream of the locked result removes all contamination surface.

## THE SEQUENCE OF RECORD

1. Construction frozen; proof_authorized flips (principal's act, per the cascade DoR).
2. Evaluator computes alpha from the frozen construction; the result is sealed RAW.
3. Alpha meets the measured value ONCE, by the evaluator, presented RAW — the blind test verdict.
4. The signature (line 20).
5. THEN, and only then: the cross-family adversarial audit — Grok and Gemini, read-only on the
   completed, scored, sealed proof, charter to refute it, as DECLARATION-READINESS certification.
   They may now see the measured value (the test is already immutable); their verdicts are DATA the
   registrar records tagged SYSTEM-INDEPENDENT; a found flaw is an honest reopen, but the original
   number stands on the record as what the original frozen construction yielded.

## AN OPTIONAL EXTRA LAYER, NOT ADOPTED HERE

A "blind-before-comparison" variant (reviewers audit after step 2 but before step 3, still blind to
the measured value) would add a reviewer-blindness evidential layer. NOT adopted; recorded so it is
a one-line change if the principal later wants it.

## FENCES (unchanged)

No cross-family model is ever shown a measured value before the blind test is scored. Reviewer output
is advisory data, never an authority that seals, enters, voids, or authorizes. The evaluator remains
the sole verdict authority for the blind test.
