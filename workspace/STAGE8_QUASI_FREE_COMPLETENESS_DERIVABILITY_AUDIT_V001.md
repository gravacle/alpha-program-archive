## 7. What a derivation would need

To turn the adopted rule into a theorem, a future derivation would have to
show all of the following before any response-facing value is inspected:

1. The primitive connected source-record generator is forced to be the
   operator-valued number-preserving functorial CAR lift of the globally
   assembled one-particle boundary superconnection.

2. No independent primitive higher-CAR, record-only, contact, or overlap
   kernel can be added while preserving the current parent action premises.

3. The exclusion is not just a restatement of "primitive means quasi-free." It
   must apply to an explicit competitor class that includes the displayed
   quartic family.

4. The theorem must preserve the source's own descendant distinction: generated
   effective quartic or record-only terms may still arise after eliminating
   shared fields or coarse-graining the complete action.

5. The theorem must not use any target response value, measured comparison, or
   later alpha-facing normalization.

6. The theorem must be stronger than CAR, locality, and disjoint monoidality
   alone, because the source explicitly says those do not derive it.

Minimal missing ingredient:

```text
INDEPENDENT_PRIMITIVE_COMPLETENESS_THEOREM_FOR_SOURCE_RECORD_ACTION
```

where "independent" means not assuming Global Boundary Descent / Quasi-Free
Completeness, not using the quartic rejection as its own premise, and not
selecting by downstream response.
