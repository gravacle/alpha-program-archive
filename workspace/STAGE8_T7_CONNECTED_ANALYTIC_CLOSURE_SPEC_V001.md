## C1 - Canonical finite connected preparation and amplitude

For every finite causally ordered cell set `K`, the execution must construct
from the sealed parent, without a separately selected state:

```text
H_K = Fock(K_Sigma) tensor R(K);
rho_in,K = rho_source,K tensor |r_K><r_K|;
P_p,K = I_source tensor |p_K><p_K|;
U_K(A) = the unique finite parent propagator.
```

The parent-selected coherent completed-branch operator is

```text
K_K(A)
  = (I_source tensor <p_K|) U_K(A)
    (I_source tensor |r_K>),
```

and its scalar amplitude is

```text
a_K(A) = omega_source,K(K_K(A));
Z_K(A) = a_K(A)/a_K(0).
```

The execution must prove:

1. every object comes from the same sealed finite parent;
2. `a_K` is a complex amplitude, not an inclusive probability;
3. the one-cell restriction is the pinned connection-returned amplitude;
4. genuinely disjoint parents give `Z_(K1 disjoint K2)=Z_K1 Z_K2`;
5. `a_K(0)` is nonzero for every admitted finite `K`; and
6. no polar return, trace, endpoint sum, or source state is selected after
   seeing a response.

If the parent does not canonically determine this scalar, C1 is blocked.

## C2 - Finite analyticity and exact Duhamel identity

For connection tangents `a,b`, define derivatives only from the same
propagator:

```text
V_K(a;t) = d/ds H_K(sa;t)|_(s=0);
G_K(a) = integral U_K(0;t,0)^dagger V_K(a;t)
                  U_K(0;t,0) dt.
```

The execution must derive the first and second derivatives of `a_K` by
Duhamel's formula and prove, at every finite `K`,

```text

```

equals the real connected transition covariance generated by those same
insertions, including every contact term produced by a nonlinear
`A -> H_K(A)` map. A covariance that omits a second derivative or changes
the preparation/final boundary fails.

The result must then test whether this exact finite-parent derivative is
identical to the `G_L` object declared at V011 lines 1283-1300. Similar
notation is not evidence of identity.

## C3 - Uniform zero-free domain containing the record interval

The execution must establish an explicit `epsilon_star>0`, independent of
finite volume and admitted cellulation in the pinned Stage-8 family, such
that:

```text

```

for the parent evaluated at the independently derived
`tau_R=pi/sqrt(2)`.

A theorem valid only for sufficiently small evolution time does not pass
unless its certified time domain contains `tau_R`. Per-state
Riemann-Lebesgue decay, a one-cell nonzero baseline, and finite-volume
continuity do not imply this uniform statement.

```text

  = sum_(connected C subset K) Phi_C(A)
```

summability bound. The bound must imply:

```text

```
