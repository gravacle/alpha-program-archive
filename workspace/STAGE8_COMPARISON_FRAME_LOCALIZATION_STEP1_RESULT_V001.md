## Conditional derivation

The conditional theorem is standard bundle logic applied only after the three
localization premises are granted.

1. The pointwise active projective stabilizer is `U(1)_rel`, so a local
   comparison frame can be changed by a smooth function `theta_i` on a patch
   `U_i`.
2. If those smooth relative-frame changes are physically redundant, then two
   frame choices related by `theta_i` must represent the same physical
   comparison data.
3. If comparison data on overlaps must be transported, ordinary derivatives
   cannot be the comparison operator: under a local frame change, `d` sees
   the extra `d theta_i`.
4. Therefore the comparison derivative must be replaced by a covariant
   derivative

   ```text
   D_i = d - i a_i.
   ```

5. Covariant patching forces the local one-forms to transform as

   ```text
   a_j = a_i + d theta_ij.
   ```

   This is exactly the transformation law printed in
   `PRIMITIVE_RELATIVE_PHASE_STABILIZER_V002.md:106-111`.

6. Hence a comparison connection is required, conditionally on the three
   localization premises.

This derivation does not consume a coupling, response value, scale, root,
eigenvalue, beta function, or measured constant.
