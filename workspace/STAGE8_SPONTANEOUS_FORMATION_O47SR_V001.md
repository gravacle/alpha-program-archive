### THE TEST APPLIED

Per the commission, OPERATED requires that formation be *the image of an operation
performed by a named thing*, and the sharp form is: **does anything external to the
record select when formation occurs?** So for each site I ask three questions:

```text
T-a  Is there a grammatical performer?                       (surface agency)
T-b  Is that performer external to the record?               (externality)
T-c  Does anything select the MOMENT, as against the moment
     being the solution of a stated condition?               (selection of the instant)
```

A site is OPERATED only if T-b and T-c both answer yes. T-a alone is surface.
