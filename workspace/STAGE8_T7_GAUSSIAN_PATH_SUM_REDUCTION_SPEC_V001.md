## P1 - Record spectral channels

For the sealed Hermitian qutrit incidence operator:

```text
c_partial=sum_(lambda in {-sqrt(2),0,+sqrt(2)}) lambda Pi_lambda,
```

derive the completed-transition weights:

```text
w_lambda=<p|Pi_lambda|r>.
```

The weights must be computed from the matrix, not entered as expected
values.

## P2 - Exact quasifree decomposition

For one cell, let `u_(c,lambda)` be the actual time-ordered one-particle
propagator generated by:

```text
h_0 + lambda v_c(t) B_c.
```

Number-preserving second quantization and record spectral resolution imply:

```text
K_c=<p|U_c|r>
   =sum_lambda w_lambda Gamma(u_(c,lambda)).
```

For causally ordered cells:

```text
K_N...K_1
 =sum_(lambda_1,...,lambda_N)
    product_j w_(lambda_j)
    Gamma(u_(N,lambda_N)...u_(1,lambda_1)).
```

This identity must be proved algebraically. It is not permission to replace
the sum by one `Gamma(k)`.

## P3 - Slater expectation

For the inherited rank-`n` pure quasifree state with occupied-orbital
isometry `V`:

```text
<Omega_V|Gamma(u)|Omega_V>=det(V^dagger u V).
```

Therefore the completed-record amplitude is the finite path sum:

```text
a_N
 =sum_(lambda_1,...,lambda_N)
    product_j w_(lambda_j)
    det[V^dagger
        u_(N,lambda_N)...u_(1,lambda_1)
        V].
```

compare them with the independent finite-Fock amplitudes within `1e-4`.
Preserve norm and report time-step convergence.
