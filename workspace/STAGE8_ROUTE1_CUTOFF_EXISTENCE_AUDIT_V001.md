## 3.4 Exactness: Suppression Cutoff Versus Genuine Termination

The corpus needs an exact response uniqueness result, not merely a practical
EFT truncation.

The exact distinction is:

```text
suppression_cutoff:
  A statement that terms above order N are suppressed by a scale or tolerance.
  It can certify a finite-order approximation, or uniqueness up to an error
  model, if the error model is allowed.
  It does not certify exact uniqueness of the response unless the remaining
  tail is itself proven irrelevant to the exact root/value.

genuine_termination:
  A statement that no admitted response-changing operators exist above order N,
  or that every such operator is exactly equivalent, exactly forbidden, or
  exactly response-null.
  This can support Section 5.3 exactness because the mutation universe becomes
  finite or exactly quotient-controlled.
```

`STAGE8_DELTAPHI_PI_PROTECTION_DETERMINATION_V001.md` lines 264-289 records
the higher-derivative class as named but not enumerated, with no sealed basis
for saying the tower is harmless. Lines 301-309 type the leading correction and
suppression claims as unbuilt because no concrete member, order, coefficient,
scale, or cutoff is supplied.

Therefore:

```text
finite_order_suppression_certifies_exact_uniqueness = false | TYPE-R | test: exact Section 5.3 uniqueness requires exhaustive coverage/no-outside decision or all-orders completion, while suppression leaves an unproven tail
genuine_termination_would_certify_exactness = true | CONDITIONAL | condition: termination must cover the exact admitted response-changing source-record-field action universe, not merely the finite record incidence sector
```
