# Complete-Qspec Connected-Kernel Locality Diagnostic Specification v001

Date: 2026-07-25

## Purpose

Test whether the frozen strictly sequential period-two Qspec regulator has a
bulk connected response kernel that decays with supercell separation and
supports a stable low-frequency expansion.

This is a falsification diagnostic before any Maxwell or coupling
identification. No response target, alpha value, or measured constant may
enter.

## Frozen construction

Use the repaired sequential cross-history map and the frozen period-two
source-mask supercell. Let `T_0` be the diagonal zero-field supercell map.
Let `T_theta` apply the same small holonomy perturbation to both cells of
one supercell.

For a field assignment supported on selected supercells, define:

```text
G(theta_vector)
 = -log |Tr_S X_final(theta_vector)|.
```

Every supercell after the last perturbation is exactly `T_0`, so
trace-preservation makes the final trace independent of how many such
trailing cells are appended.

Frozen numerical families:

```text
time steps per cell       {32, 64}
epsilon                   {1/40, 1/80}
bulk anchor supercells    {16, 32}
separations r             {0,1,...,10}
```

The prefix state at each anchor is generated by repeated application of
`T_0` from the frozen source density. No stationary state is inserted.

## Connected Hessian

For `r=0`:

```text
K_i(0)
 = [G(+epsilon e_i) + G(-epsilon e_i) - 2G(0)] / epsilon^2.
```

For `r>0`:

```text
K_i(r)
 = [
     G(+,+) - G(+,-) - G(-,+) + G(-,-)
   ] / (4 epsilon^2),
```

where the signs act at supercells `i` and `i+r`.

Apply second-order time Richardson extrapolation from 32/64 steps and then
second-order epsilon Richardson extrapolation from `1/40` and `1/80`.

## Frozen gates

1. Every evaluated amplitude must have absolute value greater than `1e-8`.
2. The two bulk anchors must agree for `r=0,...,8`:

```text
|K_16(r)-K_32(r)| / max(|mean K(r)|, 1e-8) < 0.05.
```

3. Fit `log |mean K(r)| = a + r log q` on all nonzero rows
   `r=3,...,10`. Require:

```text
at least 6 fitted rows;
q < 0.8;
R^2 > 0.90.
```

4. Define the low-frequency quadratic coefficient from the even kernel:

```text
C_R = -sum_(r=1)^R r^2 mean K(r).
```

Require truncation stability:

```text
|C_10-C_8| / max(|C_10|, 1e-10) < 0.05.
```

5. The truncated Fourier response:

```text
H_R(k)=K(0)+2 sum_(r=1)^R K(r) cos(k r)
```

must remain positive at `k in {0, pi/16, pi/8}` for both `R=8` and
`R=10`.

No threshold may be changed after execution.
