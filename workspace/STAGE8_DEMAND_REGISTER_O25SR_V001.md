### §4.1 DEMAND 1 — **STRENGTHENED.** `ANA ==> REC` holds; `REC ==> ANA` FAILS.

```text
REC  (r-3 :480-484, and the register fixed by r-3 §4.2/:489/CH-b):
     a certified n-uniform trace-norm rate for the object, STRICTLY BELOW the
     carrier volume — i.e. the ratio (rate)/(carrier object) is o(1); the
     deficiency named is "the uniform o(.) is not established".
     FORMALLY:  ||A_n|| = o(n^3).

ANA  (O5SR §2.2):
     "an exponent 3 - delta with delta > 0, holding UNIFORMLY in n".
     FORMALLY:  there exists delta > 0 and C with ||A_n|| <= C n^{3-delta}.
```

**DIRECTION 1, `ANA ==> REC`: HOLDS [DERIVED, CAS A1].**
For every `delta > 0`, `C n^{3-delta} / n^3 = C n^{-delta} -> 0`. A power saving
is a little-o. No loss.

**DIRECTION 2, `REC ==> ANA`: FAILS [DERIVED, CAS A2a, A2b, A2c, A3].**
The separating witness is exhibited, not asserted. Take

```text
        f(n)  =  n^3 / log n
```

```text
        f(n)/n^3          =  1/log n            ->  0        [CAS A2a]
        f(n)/n^{3-delta}  =  n^{delta}/log n    ->  +oo      [CAS A2b]
                                                for EVERY delta > 0
        checked also at delta = 1/2, 1/10, 1/1000, each -> +oo [CAS A2c]
        critical exponent of f:  delta*(f) = 0, while f = o(n^3) is TRUE [CAS A3]
```

`f` satisfies `REC` — it is a rate strictly below the carrier volume, and its
ratio to the carrier object is `o(1)`, which is exactly the quantity r-3's D10
display says is "never `o(1)`" for the rank × op budget [CAS B1, B2, B3]. `f`
fails `ANA` at every `delta`. **The implication fails, and it fails on a whole
family, not a contrivance:** `n^3/(log n)^m` for `m = 1, 2, 5` all separate the
two conditions [CAS A4], as does `n^3/log log n` [CAS A5].

> **FINDING 1 [DERIVED].** `ANA` is STRICTLY STRONGER than `REC`. The analytic
> demand asks for a POWER SAVING; the record asks for a LITTLE-O. Every power
> saving is a little-o; not every little-o is a power saving, and the gap is a
