
more than supply one permissible relation for `beta`.

both sealed before candidate evaluation:

```text

Requirement II: an external Lorentzian/dynamical requirement on the same cell that fixes or stabilizes the same length normalization.
Pass condition: the two requirements have exactly one common positive beta, and the uniqueness proof does not use any downstream value.
```

## 5. Frozen Falsifiers

A candidate cross-sector metric rule fails this admissibility spec if any one
of these fires:

```text
F1 beta_family_survives:
  after applying the candidate, beta remains a positive continuous family.

F2 dimensional_analogy:
  the candidate identifies R with a record interval, Planck length, horizon
  scale, or endpoint length by dimensional matching rather than by a derived
  same-cell relation.

F3 single_permission_only:
  the candidate supplies one allowed relation but no independent overdetermining
  requirement.

F4 prior_nogo_repeated:
  the candidate is one of the prior no-go objects in section 4 without a typed
  reason that its failure mode no longer applies.

F5 value_selection:
  the candidate is selected because its later output is favorable, simple,
  close to a known number, or otherwise value-shaped.

F6 namespace_or_chain_collapse:
  the candidate collapses x, rho, T_R, kappa_record, or kappa_Thomson across a
  fence rather than deriving an explicit map with the required type.
```

These falsifiers are written before any candidate is evaluated. They are not a
derivation and they authorize no computation.

## 6. Minimal Pass Condition

A candidate becomes attemptable against this spec only if it provides:

```text
1. typed same-cell inputs on both internal/projective and external/Lorentzian sides;
2. a target-blind output beta or equivalent length map;
3. two independent requirements with exactly one common positive beta;
4. an explicit clearance table against the fences in section 2;
5. an explicit escape table against every no-go in section 4;
6. frozen falsifier results against section 5.
```

Anything weaker is not a failed derivation; it is a missing specification or
an inadmissible selector.
