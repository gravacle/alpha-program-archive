### 2.2 Bindings to the completion carrier — none found

[PROVABLE] The nearest candidate is O6, and it does not bind a topology: the class

must serve, not what it lives on. Notably it also names the slot `tau_ref` — a token

candidates' names.

### 2.3 Bindings to the density space — none found either

[PROVABLE] `DUH` instantiates the notion on a density space (O9), but it **never uses

[PROVABLE] O7 is what 4d means by *"named operationally by V011"*. V011 attaches the

[PROVABLE] O8 settles what the phrase *"over `C_ref`"* modifies in sealed usage

`578eb5e9…`, which quotes the same block and contains **zero** occurrences of

`C_ref`"* modifies an **invariance**, never a **topology**. `tau_density`'s own
definitional line in O3 is the single place the phrase is attached to a topology name,
and that line is a display of candidate senses, not a typing.
