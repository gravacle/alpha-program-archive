## 6. Construction attempts and countermodels

The point of this section is not to choose a convenient formula. It shows that
the sealed stock fails to force one.

### 6.1 Stage-only accumulation

Let `D_N` denote any scalar sequence extracted from an alleged depth
divergence, and try

```text
phi_N(y) = D_N.
```

Stage compatibility would require

```text
phi_M(j_NM y) = phi_N(y),
so D_M = D_N for every N<=M.
```

A genuinely accumulating nonconstant `D_N` fails the required restriction
square. A constant sequence carries no accumulated depth information.

### 6.2 Flat-factor multiplication

Try

```text
phi_N(c,k) = D_N f(c,k),
f in Flat(S).
```

Compatibility requires

```text
D_M f_M(j_NM(c,k)) = D_N f_N(c,k).
```

Neither a compatible family `f_N` nor a renormalization relating `D_M` to
`D_N` is sealed. Even if one were postulated, multiplying by any symbolic
scalar or replacing `f` by another member of `Flat(S)` yields an unconstrained
family unless an additional normalization and generator theorem are supplied.

### 6.3 Shell coefficient composed with a cycle functional

Try

```text
phi_div(y) = c_log F(y),
```

where `c_log` is a shell or C-L3 coefficient and `F` is a cycle functional.
This fails twice:

```text
1. the relevant C-L3 coefficient is uncomputed;
2. no sealed F maps the shell/separation datum to the physical cycle action.
```

Using the already-computed shell coefficient would silently identify a
cross-cell separation divergence with the unresolved coincidence coefficient.
The sealed RL2B adjudication forbids that identification.

### 6.4 Family countermodel

Even granting a symbolic divergence scalar `d`, the current structural
conditions do not select a functional. In a local real quotient chart

is all-orders flat on `S` for every real symbolic `a`, is nonzero at generic

This countermodel is structural only. It is not a proposed physical action.
