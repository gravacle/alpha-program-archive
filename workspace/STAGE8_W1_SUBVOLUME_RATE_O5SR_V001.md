## §3 — T-1: THE CEILING IS ATTAINED — SUB-VOLUME IS NOT REACHABLE FROM CLASS DATA [DERIVED]

The first thing to settle is whether FP-1's `rank × op` step is *lossy*. If it
were, a sharper conversion inequality on the same class would be the escape and no
new carrier would be needed. It is not lossy.

**T-1 (Extremality).** Let `C(r, kappa) = { A on a space of dimension r :
||A||_op <= kappa }`. Then

```text
        sup_{A in C(r,kappa)}  ||A||_2^2  =  kappa^2 r        ATTAINED at A = kappa U, U unitary
        sup_{A in C(r,kappa)}  |tr A|     =  kappa   r        ATTAINED at A = kappa I
```

*Proof.* Upper bounds: `A` has exactly `r` singular values `s_1 >= ... >= s_r >= 0`,
each `<= kappa`, so `sum_k s_k^2 <= r kappa^2` and `|tr A| <= sum_k s_k <= r kappa`.
Attainment: for `A = kappa U` every `s_k = kappa`, so `||A||_2^2 = kappa^2 r`
exactly; for `A = kappa I` also `tr A = kappa r` exactly. There is no slack term to
recover: `sum_{k=1}^{r} kappa^2 - r kappa^2 = 0` identically. QED.
[CAS A3a exact for `r = 1..6`; A3b the identity; A3c the specialization.]

**Specialization to the wall.** With `kappa = 2` and `r = r_n = 4 n^3`:

```text
        sup ||A||_2^2 = 16 n^3        =  the sealed budget, EXACTLY   [CAS A3c]
        sup |tr A|    =  8 n^3        =  the sealed budget, EXACTLY
```

**T-1 COROLLARY (the non-implication).** For every `delta > 0` the ratio of the
class supremum to the sub-volume target is `16 n^delta -> +infinity` [CAS A4a,
A4b]. Hence:

> **No sub-volume exponent is a consequence of the class data `(rank = 4n^3,
> ||·||_op <= 2)` at any strength.** The `rank × op` ceiling FP-1 stops at is
> EXACT on that class, and no refinement of the conversion inequality can move it.

## §4 — T-2: THE DEMAND RE-TYPED — A SUB-VOLUME RATE IS A COUNTING STATEMENT [DERIVED]

T-1 says the escape must come from structure beyond `(rank, op)`. T-2 says exactly
what structure, and quantifies how much of it the carrier owes.

Let `A_n` be a dressed composite at stage `n`, with singular values
`s_1 >= ... >= s_{r_n} >= 0` and counting function `N_n(s) := #{k : s_k > s}`.

**T-2a (Layer cake, exact identities).**

```text
        ||A_n||_2^2  =  int_0^oo  2 s  N_n(s)  ds
        ||A_n||_1    =  int_0^oo      N_n(s)  ds
```

[CAS B1a, B1b: verified exactly, by piecewise integration, on four rational
singular-value lists.]

**T-2b (The delivered enclosure closes the domain).** `||A_n||_op <= 2` gives
`N_n(s) = 0` for `s >= 2`, so both integrals run on `(0, 2)` and nothing else
about `A_n` enters. [CAS B2.] **The counting function is the only remaining
freedom.** This is the exact content of "a topology in which the dressed
composites are controlled uniformly": the topology must control `N_n`.

**T-2c (Necessity — Chebyshev, exact).** If `||A_n||_2^2 <= C n^{3-delta}` then

```text
        s^2 N_n(s)  <=  sum_{k : s_k > s} s_k^2  <=  ||A_n||_2^2      so
        N_n(s)  <=  C n^{3-delta} / s^2          for every s > 0.
```

[CAS B3.] So a certified sub-volume rate **entails** a sub-volume effective rank at
every fixed threshold.

**T-2d (Sufficiency, and the SHARP threshold the carrier owes).** Suppose the
carrier supplies `N_n(s) <= c s^{-q} n^{3-delta}` on `(0,2)`. Then

```text
        ||A_n||_2^2  <=  n^{3-delta} * int_0^2 2 c s^{1-q} ds
                     =   n^{3-delta} * c 2^{3-q} / (2 - q)        [CAS B4a]
```

which is **FINITE if and only if `q < 2`**; at `q = 2` the integral is
`int_0^2 2 s^{-1} ds = +infinity`, exactly [CAS B4b, B4c].

**T-2 DERIVED CONSEQUENCE — the carrier's obligation, quantified.**

> The Chebyshev exponent produced by the rate itself is `q = 2`, and `q = 2` is
> **precisely** the divergent case. So the necessary condition T-2c is *never*
> sufficient: the gap is not an artifact of a crude estimate, it is a boundary
> case sitting exactly on the failure line. **The topology carrier must deliver a
> threshold-decay exponent `q` STRICTLY BELOW 2, uniformly in n.** That is the
> exact quantitative shape of "controlled uniformly," and it is the first time
> this commission's chain has a *number to hit* that is an exponent and nothing
> else. [CAS B5.]

This re-typing is the substantive positive yield of this build. It converts CN-1's

# B1: layer-cake identities for a finite singular-value list.
#     N(s) = #{k : s_k > s}.  Then
#        sum_k s_k^2 = int_0^oo 2 s N(s) ds        and       sum_k s_k = int_0^oo N(s) ds.
#     Verified exactly on rational singular-value lists (piecewise integration).
def layer_cake(vals):
    vals = sorted([sp.Rational(v) for v in vals], reverse=True)
    m = len(vals)
    edges = [sp.Integer(0)] + list(reversed(vals))     # ascending breakpoints
    I2 = sp.Integer(0)
    I1 = sp.Integer(0)
    for i in range(len(edges) - 1):
        a, b = edges[i], edges[i + 1]
        Ns = sp.Integer(sum(1 for v in vals if v > a))  # constant on (a,b)
        I2 += sp.integrate(2 * s, (s, a, b)) * Ns
        I1 += (b - a) * Ns
    return sp.simplify(I2), sp.simplify(I1), sp.simplify(sum(v**2 for v in vals)), sp.simplify(sum(vals))

             [sp.Rational(1,3), sp.Rational(1,5), sp.Rational(1,7)]):
