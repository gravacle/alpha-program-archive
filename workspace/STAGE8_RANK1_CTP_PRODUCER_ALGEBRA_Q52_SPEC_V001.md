## Lead

Q-80 applies. The rank-1 object does not fit the imported pure-extension bins
that have been used so far: tensor product, crossed product, inductive/direct
limit, and short exact C-star extension. Those are useful mathematical classes
for algebraic joins. The object here is heavier: it must be an algebraic carrier
plus a common-origin state/effects/quotient/measure/dynamics package produced
by one microscopic operator.

New class named here:

```text
COMMON_ORIGIN_CTP_PRODUCER_ALGEBRA
```

Definition: a common-origin CTP producer algebra is a completed
source-record-field CTP algebraic carrier together with faithful source and
record embeddings, a physical field/CTP quotient package, a positive normalized
pre-state, admitted record effects and domains, source-record-field dynamics,
and a raw contour-correlator output interface, all derived from one microscopic
source-record-field operator/dynamics.

What it resists about the old classes: the old classes can classify how
algebras are joined, but they do not by themselves supply `rho_pre`, record
effects, the physical quotient, the invariant contour/spacetime measure,
common domains, CTP branch data, or the source-record-field dynamics. A pure
tensor/crossed/direct-limit answer can therefore pass an algebraic relation test
while still failing the producer obligation.

This is a new class, not a relaxation. It is falsifiable: a candidate fails this
class if it lacks any required common-origin component listed in Section 3, or
if its tests in Section 4 fail. This specification is declared under Q-52:

```text

  instantiate the Section 3 signature from one microscopic source-record-field

```

### 3.2 Signature

A candidate `COMMON_ORIGIN_CTP_PRODUCER_ALGEBRA` must provide the following
data as one package.

```text
P0. One microscopic source-record-field operator/dynamics B0-like source.

P1. A completed source-record-field carrier/algebra A_SRF_CTP with a common
    dense domain or equivalent domain object.

P2. A faithful source embedding i_src: A_src -> A_SRF_CTP, where A_src is the
    Q-41 source CAR algebra, and the restricted state reproduces the Q-41
    source quasifree covariance/GNS data.

P3. A completed record embedding compatible with the Q-42 direct-limit record
    algebra and the Q-43 stable dressed outgoing-record monomorphism. This
    preserves the base tensor-carrier fact without promoting it to the full
    producer.

P4. A physical field/CTP package: branch embeddings, compound index ordering,
    branch metric, CTP reality/Hermiticity involution, physical source maps,
    gauge-fixed physical quotient, and invariant contour/spacetime measure.

P5. A positive normalized `rho_pre` on the completed object and admitted record
    effects `E_r`, with domains, all supplied by the same microscopic source as
    P0.

P6. Source-record-field dynamics: `S_CTP`, or an equivalent evolution such as
    `U_BR[A,g]`, acting on the common domain and supplying the normalized
    inclusive CTP amplitude at zero sources.

P7. Contact/source rules and raw contour-correlator output interface sufficient
    for later response-extraction tests to ask their own questions. This
    producer does not itself compute the physical Dyson kernel, response
    scalar, or value.
```

This signature stops before constructing P0, before deriving any selector,
before response extraction, and before any value computation. It also stops
before proving the instance-5 grading theorem or instance-6 crossed-product
exclusion; those are downstream tests that consume a candidate producer.
