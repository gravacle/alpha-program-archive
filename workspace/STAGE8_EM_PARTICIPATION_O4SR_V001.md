### §2.1 THE TEST INSTRUMENT, stated before it is used

The commission's criterion, made operational and applied uniformly:

```text
FOR a clause or failure point X, read X's OWN bytes and extract the
variables its truth-value or its failure-mode actually ranges over.
Then apply the three commissioned substitutions to the content on the
cells:  (s1) a different gauge group;  (s2) non-gauge content;
        (s3) a generic symbol class.
X is EM-ACTIVE  iff X's truth or X's failure MODE changes under some s_i.
X is EM-PASSIVE iff X's truth and failure mode are invariant under all
   three — in particular if X merely MENTIONS an EM object while
   quantifying over a class that contains it.
THE BASIS MUST BE X's OWN BYTES. A classification asserted from the
   topic, the filename, or the surrounding thread is not a result.
```

TWO DIAGNOSTICS that recur below and are stated once here, because both are read directly
off the sealed text rather than supplied by me:

```text
D-FREE-CONSTANT: if the clause's own statement carries the content-dependent
  quantity as a FREE, UNIVERSALLY QUANTIFIED CONSTANT (a multiplicity, a
  bound "c"), then no substitution that only moves that constant can move
  the clause. Substituting content moves multiplicities; it does not move
  quantified-over constants.
D-POWER-VS-CONSTANT: if the clause's failure is a statement about POWERS
  (n^3 vs n^0; degree -1 vs degree < -3), and content enters only through
  constants, the failure mode is substitution-invariant a fortiori.
```
