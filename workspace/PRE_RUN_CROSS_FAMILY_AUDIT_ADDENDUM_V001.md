## THE RULING

Immediately BEFORE the final alpha run — construction fully frozen, before proof_authorized flips —
a CROSS-FAMILY ADVERSARIAL SOUNDNESS AUDIT is run using system-independent models (Grok Super Heavy,
Gemini): read-only on the sealed frozen construction, charter to REFUTE THE PROOF, blind to every
measured value.

## THE TWO LAWFUL OUTCOMES (halt-or-proceed only)

- HALT-ON-NAMED-DEFECT: a CONCRETE, nameable soundness flaw (a spanned step that is wrong). The proof
  error is fixed (a correction, never a fit), the construction re-frozen, the audit re-run. A vague
  unease is NOT a halt — halting requires a defect stated at bytes.
- PROCEED: no defect found; the principal authorizes the run.

## FENCES (non-negotiable; the audit is worthless without them)

- BLIND to all measured values (no CODATA / 137.036 / 0.00729…) through the entire run.
- SOUNDNESS ONLY — "is this proof correct," never "does it yield alpha" / no output inspection / no
  tuning toward any number.
- NO ITERATION LOOP — the audit halts only on named defects; it may not be re-run in pursuit of a
  reviewer's satisfaction on anything but a concrete flaw (the endless-avoidance failure mode,
  explicitly barred).
- DATA NOT AUTHORITY — reviewer verdicts are recorded by the registrar tagged SYSTEM-INDEPENDENT;
  proof_authorized remains the principal's act, informed by but not delegated to them.

## AFTER PROCEED — THE RUN (unchanged from the cascade DoR, restated for adjacency)

Evaluator computes alpha from the frozen construction; Grok and Gemini INDEPENDENTLY REPRODUCE the
symbolic-to-numeric result, blind — arithmetic corroboration only, not a review of the result. Alpha
meets the measured value ONCE, by the evaluator, presented raw. The pre-run audit gets no second look
once the number exists. Then the signature (line 20).
