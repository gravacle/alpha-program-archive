## Question

## Compact-connection convention

Let `a` be the compact unit-character connection. Its observable primitive
holonomy is

```text
exp[i integral_gamma a].
```

The primitive record-carrier derivation fixes this character normalization and
the additive action phase. It does not, by itself, fix the energetic or
fluctuation cost of the connection curvature `f=da`.

In four-dimensional notation, the parity-even local public action admits

```text
S_K[a]
  = -(hbar K/4) integral f_mu_nu f^(mu_nu) sqrt(-g) d^4x
```

for every positive dimensionless `K`. Every member has:

1. the same compact `U(1)` connection and unit-character holonomy;
2. Lorentz covariance;
3. local gauge invariance;
4. a positive ordinary Maxwell stiffness; and
5. the same primitive comparison-phase normalization.

They differ in absolute field response. In the unit-character convention,

```text
alpha = 1/(4 pi K).
```

The current pre-alpha source set contains no rule selecting one positive `K`.

This test does not rely on the Gaussian countermodel proposed and retired in
`MICROSCOPIC_EXHAUSTION_IDENTIFIABILITY_GATE_V002.md`.

## Zero-bare route

Declaring the microscopic trial coefficient to be zero does not by itself
remove the ambiguity. If a quantum record functional induces one admissible
response `Gamma_ind`, then the finite local mutation

```text

  = Gamma_ind
    -(hbar c/4) integral f_mu_nu f^(mu_nu) sqrt(-g) d^4x
```

preserves the same local Lorentz and compact-`U(1)` symmetries for arbitrary
finite `c`. A complete microscopic operator, state, measure, boundary
reduction, and coincident-point prescription could forbid this family, but
none has yet been derived in the v003 clean room.

## Consequence

The primitive action character fixes how a connection history becomes
recordable:

```text
connection history -> additive action phase -> public comparison record.
```

It does not yet fix how strongly the public connection fluctuates or how much
curvature action one unit of flux costs. That second normalization is the
quantity needed for alpha.

Therefore the present premises do not uniquely determine the complete public
charged action.
