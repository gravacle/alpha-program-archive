## 5. Is The Weaker Position Coherent And Sufficient?

The weaker position is coherent:

```text
The ordinary branch takes c, hbar, and G as primitive conversion constants.
Record structure derives / selects the public gravity structure and aims to derive
dimensionless record ratios in those primitive units.
```

This is directly aligned with the primitive record-spectrum program. It says numerical values enter
only after the branch has a spectrum, the primitive conversions define record units, and remaining
dimensionless constants must be stable ratios among allowed record modes
(`gravity_emergence_newtonian_limit_derivation_v075.md:1162-1204`). It lists alpha as an
electromagnetic response ratio and lists gravitational source ratios such as `G m_i^2/(hbar c)` as
dimensionless sector targets (`gravity_emergence_newtonian_limit_derivation_v075.md:1180-1218`).

The derivation rule for such ratios is also explicit: a proposed numerical ratio is derived only by
boundary closure, sector compatibility, and Boundary Resolution, yielding a unique stable solution or
stable family with an observed member selected by recoverable boundary conditions. Source:
`gravity_emergence_newtonian_limit_derivation_v075.md:1221-1231`.

Thus a route that treats `G` as primitive and derives alpha as a dimensionless record ratio is
conceptually coherent.

It is not by itself sufficient to compute alpha in the current corpus. It still requires the
record-side object that selects the dimensionless ratio: the electromagnetic response operator /
record-spectrum solution / response bridge. The gravity arm says the charge sector target is to
derive the electromagnetic response ratio alpha (`gravity_emergence_newtonian_limit_derivation_v075.md:1241-1243`),
and the structural field-equation theorem leaves the low-energy value of alpha open
(`gravity_emergence_newtonian_limit_derivation_v075.md:6171-6185`).

The cleanroom B0 system also carries the historical conversion constants as input context while
separately reporting that the full primitive inventory is not supplied:
`STAGE8_B0_JOINT_IPRIM_CODOMAIN_CONSTRAINT_SYSTEM_V001.md:190-230`.

Therefore:

```text

weaker_position_sufficient_for_alpha_now = false | TYPE-U |
  would-build: the record-sector electromagnetic response / dimensionless-ratio selector
               that computes alpha in primitive ordinary-branch units
```

Cost relative to the stronger emergence claim:

```text
The program can honestly claim:
  alpha derived from record structure given c, hbar, and G as ordinary-branch primitive conversions.

The program cannot honestly claim, on current sealed text:
  G itself, or the gravitational normalization entering ell_P, is derived from record structure.
```

That is not a refutation of gravity emergence. It is a ceiling on the current proof claim.
