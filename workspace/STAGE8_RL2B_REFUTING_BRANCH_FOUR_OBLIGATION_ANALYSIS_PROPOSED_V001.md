## 3. Proposed Reading

The refuting branch does **not** imply that connected extensivity is false.
The campaign opening itself says that if R-L2b fails, the reason connected
extensivity is unresolved is R-L2b's named failure. That is an unresolved-status
sentence, not a falsity sentence.

The refuting branch also does **not** leave the four obligations untouched in
the practical sense. It defeats the only written one-estimate campaign that was
supposed to carry all four. Therefore the current route cannot honestly pass
any of the four via R-L2b as written.

The asymmetric result is:

```text
closing branch:
  R-L2b closes  =>  all four obligations discharge by the single-estimate
                    campaign.

refuting branch:
  R-L2b as written is refuted  =>  the single-estimate campaign cannot discharge
                                   the four obligations; connected extensivity
                                   remains unresolved for the named R-L2b reason,
                                   not refuted by this fact alone.
```
