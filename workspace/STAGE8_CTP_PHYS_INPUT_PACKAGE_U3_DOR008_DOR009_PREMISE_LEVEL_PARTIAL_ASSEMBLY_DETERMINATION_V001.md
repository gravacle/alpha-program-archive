### 2.2 Orbit map and quotient

Define the relative-holonomy map

```text

q_N(z_+,z_-)_j = r_j := conjugate(z_(-,j)) z_(+,j).
```

It is invariant under the common action:

```text

 = conjugate(g_j z_(-,j) g_(j-1)^dagger)
   (g_j z_(+,j) g_(j-1)^dagger)
 = conjugate(z_(-,j)) z_(+,j)
 = r_j.
```

The invariant is complete. If two doubled histories have the same `r`, choose
`g_0=1` and recursively set


values agree.
