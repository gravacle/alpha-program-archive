# Parent-State Covariance Principle v001

Date: 2026-07-24

## Status and provenance

This is an adopted Level-1 Gravacle principle. It is target-value-free but
historically target-aware: the alpha program already existed when the
principle was formulated. It is frozen before any new parent-to-outgoing
spectral calculation.

The principle does not compute alpha and does not select a microscopic parent
action by itself.

## Principle

For every physical finite boundary complex `K`, one complete microscopic
parent supplies, together:

```text
the observable algebra A_K;
the parent-selected state omega_K;
the parent derivation delta_K;
the public record subalgebra R_K;
and the first-opening root data q_K.
```

For every physical exhaustion inclusion `iota_KL:A_K -> A_L`, these objects
must form one covariant system:

```text
omega_L o iota_KL = omega_K;

delta_L o iota_KL
  = iota_KL o delta_K
```

on stabilized interior observables. A boundary correction is admissible only
when it is derived from the same parent and converges as a specified boundary
cocycle; it may not be chosen independently.

The physical outgoing theory is the locally normal GNS limit of that single
covariant system:

```text
A_infinity = inductive_limit(A_K);
omega_infinity = projective_limit(omega_K);
(pi_infinity,H_infinity,Omega_infinity)
  = GNS(A_infinity,omega_infinity).
```

The limiting derivation must generate a strongly continuous outgoing
evolution in this representation. Its root, spectral measure, bound states,
continuum, write defect, and durability law must be inherited from the same
finite parent sequence.

## Physical exhaustion

The inclusions above add physically available future boundary cells. They do
not subdivide one primitive cell into arbitrarily smaller primitive cells.
The previously derived intrinsic-cell measure remains attached to each
primitive cell.

## No-separate-selection rule

The following may not be supplied independently after the finite parent has
been chosen:

```text
a continuum vacuum or outgoing state;
a continuum generator;
a preferred positive branch;
a root profile;
a spectral density;
a cutoff or regulator weight;
or a post-write decoupling rule.
```

Each must descend naturally from the same parent action and the same
exhaustion maps. Agreement with alpha, an endpoint value, or any other known
target is not an admissible selector.

## First derivation route

The first route tested under this principle is parent-derived scattering:
the finite write interaction must prepare a parent-selected outgoing state,
and the outgoing algebra and dynamics must be the asymptotic limit of that
same interaction.

This route is a declared test order, not an assumption that scattering must
succeed.

## Falsifiers

The principle fails for a proposed parent or exhaustion if any of the
following occurs:

```text
finite states are not restriction-compatible;
finite derivations fail interior covariance;
an undetermined boundary cocycle survives;
different admissible exhaustions give inequivalent locally normal limits;
the outgoing state or generator must be chosen separately;
the first-opening root has no natural finite-parent lift;
the root is absent from the limiting form domain;
or the claimed spectrum is not generated by the same parent.
```

## Scope

This principle can select or reject parent-to-outgoing constructions. It does
not, without a separate derivation:

```text
exclude every response-inequivalent microscopic parent action;
derive the complete relativistic parent;
fix the absolute charged stiffness;
or compute alpha.
```
