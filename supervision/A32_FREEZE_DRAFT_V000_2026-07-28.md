## LANE-SPECIFIABLE — mechanical, no judgement, ready to seal

- **Query and pagination.** Full endpoint path, query parameters, page-size rule, sort rule, retry
  rule, rate-limit behaviour, termination condition, failure behaviour. No manual addition or removal.
- **Inclusive UTC cutoff.** One timestamp `T_cutoff`; include records with registry timestamp
  `<= T_cutoff`. Unparseable timestamp => machine exclusion with reason.
- **Response schema.** Registry record ID, observable definition text, value or masked-outcome handle,
  units, uncertainty/covariance metadata, kinematic/domain metadata, source identifier,
  timestamp/version, provenance URL.
- **Canonical field mapping.** Registry fields -> canonical JSON keys, typed. Missing required key =>
  machine exclusion, never human repair.
- **Canonical JSON.** RFC-8785, UTF-8, sorted keys, normalized number/string handling.
- **Canonical observable ID.** `canonical_id = SHA256(RFC8785(canonical_source_record))` where the
  record includes registry source ID, record ID, observable definition, units, domain, source
  identifier — **and NOT the observed value.**
- **Deterministic dedup.** Cluster key = normalized source identifier + normalized observable
  definition + units + domain. Keep lexicographically lowest `canonical_id`; emit all suppressed IDs
  with reasons.
- **Collector output.** Raw page bytes, `SHA256(raw_page_bytes)` per page, canonical candidate JSONL,
  exclusion JSONL, duplicate report, collector version hash, collection transcript.
- **Custodian commitments.** Independent custodian, one 256-bit salt per candidate from auditable
  external randomness or hardware entropy. Payload = RFC-8785 JSON of canonical outcome value,
  uncertainty, covariance, units, source identifier. Commitment =
  `SHA256(salt || RFC8785(canonical_outcome_payload))`. Custodian attests no payload disclosed.
- **Selection rule.** After PREDICTION-MAP-SEAL, with `B` the canonical beacon value and `H_spec` the
  final spec hash: sort eligible IDs by `SHA256(H_spec || B || UTF8(canonical_id))`, select lowest.
- **Contamination audit.** Search all accessible repository history, attachments, logs, prompts,
  tickets, browser-history exports where available, and lane artifacts for the selected
  `canonical_id`, source identifier, observable definition and outcome payload BEFORE unmasking. Any
  prior outcome access FAILS A32.
- **Prediction-map interface.** Immutable
  `(sealed_theory_output_record, canonical_candidate_record) -> prediction_payload`, carrying predicted
  value, units, theory uncertainty, covariance if vector-valued, propagation trace, comparator outputs,
  structure-sensitivity statistic, pass/fail statistic template. Values wait downstream; the interface
  freezes now.
- **Uncertainty treatment.** Theory uncertainty from sealed prediction payloads only; comparator
  uncertainty from preregistered comparator payloads only; measurement uncertainty/covariance from the
  custodian commitment payload, uneditable after commitment. Vector observables use Mahalanobis
  distance with combined covariance; singular covariance fails eligibility unless a projection rule was
  frozen beforehand.

## *** PRINCIPAL — SIX ITEMS AWAITING RATIFICATION ***

These are judgements that determine what counts as PASSING. They are not lane-specifiable.

1. **REGISTRY/API SOURCE.** Selects the observable universe, so the lane specified required properties
   and declined to choose the source: one public machine-readable registry/API, externally maintained,
   stable pagination, public timestamps or versioning, public values or custodian-accessible masked
   outcomes, units, uncertainty, source identifiers.
2. **EXTERNAL BEACON SOURCE.** Protocol-significant. Rule: predeclared public FUTURE randomness beacon
   with canonical retrieval URL, event time, value parser, outage fallback, and NO discretion.
3. **SAME-ALPHA COMPARATOR CLASS.** A comparator qualifies only if independently specified over the
   same canonical candidate records, using the same alpha convention/value supplied to BID, with no
   candidate-specific fitted parameter, only parameters frozen before candidate-universe construction,
   emitting value/unit/uncertainty in the same schema.
4. **CALIBRATION RULE.** BID and comparator evaluated with identical alpha input and identical
   candidate metadata. Any comparator requiring refit, channel-specific coefficient, or post-selection
   for a candidate is ineligible FOR THAT CANDIDATE.
5. **DISTINCTNESS THRESHOLD — proposed `D >= 5`**, where
   `D = |mu_BID - mu_comp| / sqrt(sigma_BID^2 + sigma_comp^2 + sigma_meas^2)`
   after unit conversion and covariance projection. Deliberately conservative, conventional, and fixed
   BEFORE any prediction. **An empty eligible set FAILS CLOSED rather than the threshold being lowered
   later.**
6. **OBSERVABLE FAMILY.** All machine-enumerated registry candidates satisfying eligibility and
   computability under the frozen prediction-map interface. NO human subfamily may be carved out after
   registry collection.

## REVIEWER NOTE

The threshold is the item whose lateness voids the test, and item 5 handles it the right way: an
arbitrary-but-conservative value fixed in advance and disclosed is worth more than a principled one
chosen afterwards. The fail-closed clause on the empty set is what stops `D` being renegotiated when
the eligible set turns out small — which is exactly how a holdout of this kind normally dies.

Not sealed. Not authority. `alpha_computed = false`; `proof_authorized = false`.
