## The battery: theorem obligations T1–T16

Each maps to a clause of Gate 5's sealed "Pass requires" block (V011
1728–1757), made operational. Order is execution order; later obligations
may consume earlier outputs; none may weaken an earlier sealed result.

sealed F₁ operator (Gate-4 unique differential class). No curvature may be
supplied by hand. Pass: the curvature object is computed from F₁ with a
machine-checkable derivation chain to the Gate-4 core.

**T2 — Augmentation-ideal order.** Prove the augmentation-ideal order claims
algebraically (exact integer/symbolic computation; no numerical tolerance).

**T3 — Clifford square benchmark.** The Clifford square returns the frozen
signed leading coefficient K_Pauli,kin = −1/2 with invariant magnitude 1/2.
This is a fixed benchmark, not a tunable: any other value is a FAIL, not a
recalibration.

**T4 — Durable-record interval.** Admit the complete τ>0 interval family and
derive the least positive durable-record interval without target access.
Consistency check (not a selector): the derived interval must reproduce the
independently sealed τ_R = π/√2 first-opening lock; a mismatch is a
reported contradiction, never a repair.

root-generated preparation domain from first-opening semantics; enumerate
every translation-invariant competitor; each competitor is excluded by
