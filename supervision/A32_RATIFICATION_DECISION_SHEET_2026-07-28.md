## THE SIX DECISIONS

### 1. Registry / API source — WHICH ONE?
- Draft: names none, by design ("Selects the observable universe, so the lane specified
  required properties and declined to choose the source").
- Required properties (draft): one public machine-readable registry/API, externally
  maintained, stable pagination, public timestamps or versioning, public values or
  custodian-accessible masked outcomes, units, uncertainty, source identifiers.
- Corpus constraints: candidates must "possess a public independently measured value and
  uncertainty" and "not share the alpha datum or a deterministic re-expression of it"
  (V011:1985-1990). Collector must exhaust every page, publish raw response hashes and a
  machine-generated inclusion/exclusion report (V011:1965-1967). NO source is named anywhere;
  CODATA/PDG/NIST appear in the cleanroom only inside prohibitions (bounded).
- Defer = no candidate universe can be constructed; SPEC-SEAL unreachable.

### 2. External randomness beacon — WHICH ONE?
- Draft rule: a predeclared public FUTURE randomness beacon with canonical retrieval URL,
  event time, value parser, outage fallback, and NO discretion.
- Corpus constraints: "Target selection uses the first public value emitted after
  PREDICTION-MAP-SEAL by the predeclared external randomness beacon" (V011:1996-1998);
  beacon substitution = A32_FAIL (V011:2013). NO beacon named anywhere (bounded: no
  drand/NIST-beacon hits in cleanroom or supervision).
- Defer = the selection rule (mechanical item 10) cannot execute.

### 3. Same-alpha comparator class — WHAT QUALIFIES?
- Draft qualification rule: independently specified over the same canonical candidate
  records, same alpha convention/value supplied to BID, no candidate-specific fitted
  parameter, only parameters frozen before candidate-universe construction, same output
  schema.
- Corpus constraints (qualitative half already sealed-required): "BID and at least one
  preregistered comparator calibrated to the same alpha must make distinct predictions"
  (V011:1991-1992); identical-predictions comparator = A32_FAIL (V011:2014). NO class named.
- Defer = the operative warning fires: "A32 remains named but NON-EXECUTABLE; later
  selection would reopen fitting."

### 4. Calibration rule — RATIFY THE STATED RULE?
- Draft rule (the draft's own default): BID and comparator evaluated with identical alpha
  input and identical candidate metadata; any comparator requiring refit, channel-specific
  coefficient, or post-selection for a candidate is ineligible FOR THAT CANDIDATE.
- Corpus constraints: the alpha convention is already frozen — alpha(0) = 1/(4 pi
  kappa_Thomson), "Only kappa_Thomson may enter" (V011:1661-1663, :2202; matrix V005:78).
  The prohibition triplet (refit / channel coefficient / post-selection) is verbatim
  V011:1987-1988. The ineligible-for-that-candidate clause is an additive refinement with no
  sealed counterpart or contradiction.
- Defer = comparators are not "same-alpha" in any checkable sense; item 3 dies with it.

### 5. Distinctness threshold — RATIFY D >= 5?
- Draft proposal: D >= 5 with D = |mu_BID - mu_comp| / sqrt(sigma_BID^2 + sigma_comp^2 +
  sigma_meas^2), unit-converted, covariance-projected; "deliberately conservative,
  conventional, and fixed BEFORE any prediction"; AN EMPTY ELIGIBLE SET FAILS CLOSED rather
  than the threshold being lowered later.
- Corpus constraints: the fail-closed-on-empty-set consequence is ALREADY sealed-required
  (V011:2011-2015 "an empty eligible set ... returns A32_FAIL"; matrix V005:82). The NUMBER
  and the statistic are pure principal judgment — no numeric threshold, no Mahalanobis, no
  formula exists anywhere in the corpus outside the draft (bounded). Nothing contradicts
  D >= 5; nothing forces it.
- Defer = the reviewer's warning: "The threshold is the item whose lateness voids the test...
  the fail-closed clause on the empty set is what stops D being renegotiated when the
  eligible set turns out small — which is exactly how a holdout of this kind normally dies."

### 6. Observable family — RATIFY THE ALL-ELIGIBLE RULE?
- Draft rule (the draft's own default): ALL machine-enumerated registry candidates satisfying
  eligibility and computability under the frozen prediction-map interface; NO human subfamily
  carved out after registry collection.
- Corpus constraints: the five eligibility conditions are sealed-specified (V011:1983-1993);
  "No human choice among candidates is allowed" (V011:2005); manual curation is a stop-rule
  violation (V011:2088-2089).
- Defer = any later carve-out is the hand-curation that fails A32 outright.
